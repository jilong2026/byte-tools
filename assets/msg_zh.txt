# This file is DATA, not code. The .bat files stay pure ASCII on purpose: a
# multibyte .bat plus "chcp 65001" desyncs cmd.exe's read offset and it starts
# executing the middle of a line. Chinese text therefore never appears in the
# script itself, only here.
#
# Format:  key=value     (one per line, '#' starts a comment)
# Line endings MUST stay LF. cmd's "for /f" leaves the CR of a CRLF file inside
# the value, and echo then emits CR CR LF: every message gets a stray carriage
# return. bt_boot_script_tests.py asserts this.
# {0} in a value is replaced by the third argument of call :say.
# Do not use '!' in a value: FOR-variable substitution plus delayed expansion
# eats it. Full-width punctuation is fine.
# Indentation is part of the message, keep it aligned with the English text.
